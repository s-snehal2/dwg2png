# DWG → PNG Converter (frontend)

This directory contains the Next.js app that converts DWG files to PNG images.

See the repository root [`README.md`](../README.md) for setup, configuration,
API endpoints, and testing instructions.

Quick start (from this directory):

```bash
npm install
npm run dev        # development server on http://localhost:3000
# or for production:
# npm run build && npm start

npm test           # vitest: unit + integration
npm run lint       # eslint
```
